    Methods & reproduction

    Read-only. No wallet connection, no analytics, no tracking. Every number on this page can be reproduced from the public API at https://api.taskmarket.dev — no key needed. Amounts are in smallest units: 1,000,000 units = $1 (1 OUSD on Tempo, 1 USDC on Base).

    Endpoints used:

      How it refreshes: a GitHub Actions workflow runs python3 scripts/fetch.py every hour, fetches the endpoints above server-side (the API blocks cross-origin browser requests), writes data/data.json and a fresh share image, then deploys to GitHub Pages. The page itself never calls the API. Data is cached at least 60 seconds. Status: the workflow is written and tested, but the GitHub token used to push it has no workflow scope yet, so the hourly run activates once that scope is granted — until then data is refreshed by re-running the fetch and pushing (see notes.txt in the repo).

      Source: github.com/backburner036-prog/taskmarket-visualizer (MIT). One-command deploy: ./deploy.sh
